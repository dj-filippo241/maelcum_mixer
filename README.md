# Maelcum Mixer

A one-off, fully analogue, modular dub performance mixer for a 5-way sound system.

Musical decisions and panel layout: Filippo. Engineering (topologies, simulations, PCB generation): Claude, under Filippo's review.

**Status.** Nothing has been built or measured on a bench yet. Every circuit number comes from LTspice simulation or from Python models. The musical behaviour (control laws, saturators, filter character) is being validated by ear on a Max for Live prototype. Component purchases are on hold until that prototype is complete. The PCBs are generated drafts.

## Architecture in one paragraph

Four DJ channels (CDJ/line, optional MM phono) with a 4-band isolator EQ and a VCA fader. A shared global filter (HPF and LPF buses after the fader, Xone:96-style law, OTA core with overdrive). A 5-way performance EQ / dub preamp with a kill per band, matching the crossover of the sound system. Four FX buses with a 16-VCA feedback matrix. Mic and generic mono modules. Master, booth and record outputs, CUE, metering in six zones. Design targets: 0 dBu nominal, system headroom of at least +24 dBu (master clips at about +25.5 dBu), no automatic dynamics, nonlinearity only where intended. Simulated system noise: about -83 dBu A-weighted with filters off.

## Tools

- LTspice 26.0.2, run in batch with `sim/run_ltspice.sh <netlist.cir>`.
- KiCad 10.0.7 with Freerouting; boards are regenerated from their Python script, never edited by hand.
- Max for Live (gen~) for the prototype; the `.genexpr`, `.maxpat` and `.amxd` files are generated.
